# Madalena Maths

A single-page marketing site for Madalena, a GCSE and Further Maths tutor based online.

## Technologies

- Plain HTML, CSS, and vanilla JavaScript — no build step required
- Google Fonts (Lora, Plus Jakarta Sans)
- Hosted on Netlify as a static site

## Running locally

Open `index.html` directly in a browser, or use any static file server:

```bash
npx serve .
```

The site is also fully functional when deployed to Netlify — just push to the connected branch.
